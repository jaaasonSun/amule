iOS Server Operation Parity Evidence
====================================

Implemented bridge parity for daemon server operations:
- servers
- server-disconnect
- server-add
- server-remove
- server-update-from-url

Key changes:
- Extended iOS BridgeProtocol and IOSInProcessBridgeAdapter with server list, disconnect, add, remove, and update-from-url methods.
- Added C wrapper declarations/forwarders for the same operations through AMuleECBridgeCore.
- Updated FakeBridgeAdapter capabilities and fake server-operation implementations.
- IOSAppModel now fetches daemon servers through bridge.servers(config:) when the bridge advertises support.
- disconnectServer now uses explicit serverDisconnect instead of substituting serverConnect(nil, nil).
- Local userServers remain local bookmarks; duplicate local endpoint bookmarks are rejected.
- ServersView labels daemon server list separately from local bookmarks and makes daemon mutations explicit.
